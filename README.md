
# 🎵 Reproductor de Música Z80  
## Mantel Producciones – Microprocesadores (UCU Campus Salto)
### Integrantes: Ignacio Silva, Renzo Beretta y Lucas Chiappini

Este repositorio pertenece al grupo **Mantel Producciones**, estudiantes de la **Universidad Católica del Uruguay – Campus Salto**, en el curso de **Microprocesadores**, bajo la guía del profesor **Jonatan Piuma**.

## 📘 Descripción del Proyecto  
El objetivo principal de este repositorio es desarrollar un **reproductor de música utilizando el microprocesador Z80**.  
La idea consiste en implementar, mediante programación en ensamblador y el uso de lógica digital, un sistema capaz de **reproducir la canción del Z80**, una melodía clásica utilizada como referencia en proyectos de audio basados en este microprocesador.

El proyecto integra:
- Programación en ensamblador Z80  
- Manejo de hardware modular  
- Uso de buses de datos  
- Diseño de un sistema de sonido simple y programable
